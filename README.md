# Model Picker для Claude Code

Плагин учит Claude тратить меньше: брать для каждой задачи самую дешёвую модель, которая справится, и не тянуть
одну сессию бесконечно.

- **Скилл `pick-model`** — лестница из четырёх ступеней (Haiku → Sonnet medium → Sonnet high → Opus) и три вопроса,
  по которым Claude выбирает ступень. Работает при запуске новых сессий в приложении Claude (`start_session`) и
  сабагентов (`Agent`), а также в терминале. Плюс правило «одна задача — одна сессия»: закончил задачу — следующую
  предложи в новой сессии с коротким брифом.
- **Хук-сторож** — когда контекст сессии больше 150 тыс. токенов, напоминает Claude вынести новую работу в новую
  сессию и один раз показывает вам строку «Сессия длинная…» (повторно — на +100 и +200 тыс.).

Постоянно в контексте — около 80 токенов (описание скилла). Полный текст скилла (~900 токенов) подгружается, только
когда нужен. Хук работает вне контекста модели и токенов не тратит, пока контекст ниже порога.

## Установка

### Вариант 1. Через GitHub (обновления одной командой)

Нужен Claude Code в терминале (`claude`). Выполните в обычном терминале:

```bash
claude plugin marketplace add Odin41/model-picker
claude plugin install model-picker@model-picker-hub
```

Обновить до свежей версии:

```bash
claude plugin update model-picker@model-picker-hub
```

### Вариант 2. Папкой (работает и в приложении Claude, без терминала)

1. Скачайте архив (на GitHub: **Code → Download ZIP**) или возьмите `model-picker.zip` у автора и распакуйте.
2. Положите папку в папку скиллов Claude и назовите её `model-picker`:
   - Windows: `%USERPROFILE%\.claude\skills\model-picker`
   - macOS / Linux: `~/.claude/skills/model-picker`
3. Проверьте, что внутри `model-picker` сразу лежит папка `.claude-plugin` (а не ещё одна вложенная папка).
4. Перезапустите Claude.

Обновление — заменить папку новой версией.

## Требования

- **Скилл** работает везде без дополнительных программ.
- **Хуку** нужен Python 3 (`python3` или `python`). Без Python хук просто молчит, ошибок не будет.
- **Windows:** хуки запускаются через Git Bash, он ставится вместе с [Git for Windows](https://git-scm.com/download/win).

## Настройка

Порог сторожа меняется переменной `CONTEXT_GUARD_WARN` в `~/.claude/settings.json`:

```json
{
  "env": { "CONTEXT_GUARD_WARN": "200000" }
}
```

Таблицу моделей можно поправить под себя в `skills/pick-model/SKILL.md`.

## Если у вас уже есть похожие правила

Если такие же правила лежат в `~/.claude/CLAUDE.md` или такой же хук прописан в `settings.json`, уберите дубли,
иначе напоминания придут дважды. В `CLAUDE.md` достаточно одной строки, чтобы скилл загружался надёжнее:

```markdown
- Перед каждым `start_session` и запуском сабагента, а также когда задача сделана, загрузи скилл `pick-model`.
```

## Удаление

- Вариант 1: `claude plugin uninstall model-picker@model-picker-hub`
- Вариант 2: удалить папку `~/.claude/skills/model-picker`

## Для автора

### Структура

```text
model-picker/
├── .claude-plugin/
│   ├── plugin.json         # манифест плагина
│   └── marketplace.json    # этот же репозиторий — маркетплейс из одного плагина ("source": "./")
├── skills/pick-model/
│   └── SKILL.md            # правила выбора модели и effort
├── hooks/
│   ├── hooks.json          # подключение хука UserPromptSubmit
│   └── context_guard.py    # хук-сторож длины сессии
├── README.md
└── LICENSE
```

### Проверка

```bash
claude plugin validate .
```

Должно закончиться строкой `Validation passed`. Предупреждения про `version` и `icon` ожидаемы: версия не указана
специально (см. ниже), иконка нужна только для каталога Anthropic.

### Публикация на GitHub

1. Создайте пустой репозиторий на GitHub (без README и лицензии — они уже есть).
2. Из этой папки:

```bash
git init -b main
git add .
git commit -m "model-picker: первая версия"
git remote add origin https://github.com/Odin41/model-picker.git
git push -u origin main
```

3. Замените в этом README `Odin41/model-picker` на настоящий адрес.

Репозиторий может быть приватным: тогда установить плагин смогут только те, у кого есть к нему доступ.

### Выпуск обновлений

В `plugin.json` нет поля `version`, поэтому версией служит хеш коммита: достаточно запушить изменения, и
`claude plugin update` у друзей подтянет новую версию. Если когда-нибудь добавите `version`, его придётся
повышать в каждом релизе, иначе обновление не придёт.

### Архив для раздачи

Запустите `build.bat` (двойной клик или из командной строки). Скрипт проверяет плагин через `claude plugin validate`
(если `claude` найден) и собирает `dist\model-picker.zip` из последнего коммита, без служебных файлов гита.
Незакоммиченные правки в архив не попадут — скрипт об этом предупредит. Папка `dist/` в гит не попадает.

### Разработка

Установленная копия (`~/.claude/skills/model-picker`) и эта папка — разные места. Чтобы правки сразу работали у
вас, замените установленную копию ссылкой на репозиторий (Windows, командная строка `cmd`):

```bat
rmdir /s /q "%USERPROFILE%\.claude\skills\model-picker"
mklink /J "%USERPROFILE%\.claude\skills\model-picker" "D:\ai\claude\plugins\model-picker"
```

Изменения подхватываются при старте новой сессии.
